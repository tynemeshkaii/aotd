# Plans

This folder keeps current planning and reference docs visible.

Use `AGENTS.md` as the source-of-truth index for current plans. Files in `archive/` are historical phase
plans, retired implementation notes, and earlier design explorations. They can be useful for context, but
they are not product truth unless a current plan or current code points back to them.

Keep new active plans at this level. Move retired plans into `archive/` once their decisions have shipped or
been superseded.
