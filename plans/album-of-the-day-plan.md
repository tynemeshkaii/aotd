# Album of the Day — Полный план разработки

> Приложение для iOS, MVP: Spotify-интеграция, алгоритм рекомендации альбома дня, оценки, социальные фичи.
> Стек подобран так, чтобы работать с Claude и Claude Code без знания программирования.

---

## Стек технологий

| Слой | Технология | Почему |
|---|---|---|
| Мобильное приложение | **Expo + React Native** | Не нужно открывать Xcode, тестирование прямо на телефоне через приложение Expo Go, сборка для App Store через облако |
| База данных + бэкенд | **Supabase** | Всё в одном: база данных, авторизация, API. Есть удобный веб-интерфейс, можно смотреть данные как в Excel |
| Алгоритм рекомендаций | **Supabase Edge Functions** (TypeScript) | Серверный код прямо в Supabase, не нужен отдельный сервер |
| Внешние API | **Spotify API** + **Last.fm API** + **MusicBrainz** | Spotify — библиотека пользователя; Last.fm — рейтинги и популярность альбомов; MusicBrainz — метаданные (жанры, год, обложка) |
| Сборка и публикация | **Expo EAS** | Собирает .ipa файл для App Store без Xcode на твоём компьютере |

## Аккаунты которые нужно создать (до начала разработки)

Всё это нужно сделать один раз в самом начале. Большинство бесплатно.

1. **Spotify for Developers** — [developer.spotify.com](https://developer.spotify.com)
   Создать "приложение" в дашборде → получишь `Client ID` и `Client Secret`

2. **Supabase** — [supabase.com](https://supabase.com)
   Бесплатный план покрывает MVP с запасом

3. **Last.fm API** — [last.fm/api](https://www.last.fm/api)
   Бесплатно, нужен только `API Key`

4. **Apple Developer Program** — [developer.apple.com](https://developer.apple.com)
   $99/год, нужен для публикации в App Store. Можно зарегистрировать в самом конце, перед релизом

5. **Expo** — [expo.dev](https://expo.dev)
   Бесплатно, нужен для сборки приложения

## Фазы разработки

---

### Фаза 0 — Подготовка среды
**Цель:** установить всё необходимое на компьютер и проверить что работает
**Примерное время:** 1-2 дня

**Что делаем:**
- Устанавливаем Node.js (движок для JavaScript)
- Устанавливаем Expo CLI (инструмент командной строки)
- Устанавливаем приложение **Expo Go** на iPhone (для тестирования)
- Создаём проект в Supabase
- Создаём приложение в Spotify Developer Dashboard
- Проверяем что всё запускается

**Как работаем с Claude Code:**
Открываешь Claude Code в терминале, говоришь "помоги мне установить и настроить окружение для Expo проекта" — он проведёт тебя через каждый шаг с конкретными командами.

---

### Фаза 1 — Скелет приложения
**Цель:** запустить базовое приложение с навигацией между экранами
**Примерное время:** 1 неделя

**Что делаем:**
- Создаём Expo проект
- Настраиваем навигацию (экраны: главный, профиль, друзья, история)
- Подключаем Supabase к проекту
- Делаем базовую структуру базы данных (таблицы: users, albums, ratings, friends)
- Деплоим первую версию на телефон через Expo Go

**Результат фазы:** на телефоне открывается приложение, можно тыкать по экранам, данные пишутся в базу

---

### Фаза 2 — Авторизация через Spotify
**Цель:** пользователь может войти в приложение через свой аккаунт Spotify
**Примерное время:** 1-2 недели

**Что делаем:**
- Настраиваем Spotify OAuth в Expo (через библиотеку `expo-auth-session`)
- После входа получаем `access_token` от Spotify
- Сохраняем токен в Supabase
- Загружаем базовые данные профиля (имя, аватар)
- Делаем экран профиля с этими данными

**Результат фазы:** кнопка "Войти через Spotify", после нажатия — приложение знает кто ты

---

### Фаза 3 — Импорт библиотеки из Spotify
**Цель:** приложение знает какие альбомы уже есть у пользователя
**Примерное время:** 1-2 недели

**Что делаем:**
- Запрашиваем у Spotify API список сохранённых альбомов пользователя
- Учитываем что альбомов может быть много — делаем постраничную загрузку (Spotify отдаёт по 50 штук)
- Сохраняем список в Supabase (таблица `user_library`)
- Делаем экран "Моя библиотека" для проверки что всё загрузилось
- Добавляем кнопку "Обновить библиотеку" (синхронизация)

**Результат фазы:** приложение видит все твои альбомы из Spotify

---

### Фаза 4 — Алгоритм "Альбом дня"
**Цель:** каждый день пользователь получает один рекомендованный альбом которого нет у него в библиотеке
**Примерное время:** 2-3 недели (самая сложная фаза)

**Что делаем:**
- Настраиваем Last.fm API — получаем топовые альбомы по жанрам
- Настраиваем MusicBrainz — получаем метаданные альбомов
- Пишем Edge Function в Supabase: алгоритм подбора
  - Берём жанры и артистов из библиотеки пользователя
  - Ищем высокооценённые альбомы в этих жанрах через Last.fm
  - Фильтруем то что уже есть в библиотеке
  - Из оставшегося выбираем один (с элементом случайности)
  - Сохраняем как "альбом дня" для этого пользователя
- Настраиваем ежедневное обновление (новый альбом в полночь)
- Делаем историю — список всех прошлых альбомов дня

**Логика алгоритма подробнее:**
```
1. Взять топ-5 жанров пользователя из его библиотеки
2. Через Last.fm получить топ-200 альбомов этих жанров
3. Убрать те что уже есть в библиотеке пользователя
4. Убрать те что уже были рекомендованы раньше
5. Отсортировать по рейтингу Last.fm (слушателей + скробблов)
6. Из топ-20 выбрать случайный — это и есть альбом дня
```

**Результат фазы:** каждый день новый альбом, подобранный под вкус пользователя

---

### Фаза 5 — Карточка альбома и оценки
**Цель:** красивая карточка с инфой об альбоме и возможность поставить оценку
**Примерное время:** 1-2 недели

**Что делаем:**
- Дизайн карточки альбома:
  - Обложка альбома (большая)
  - Название, артист, год, жанр
  - Краткая инфа (количество треков, длительность)
  - Рейтинг Last.fm (сколько людей слушают)
  - Кнопка "Открыть в Spotify" (deep link)
- Система оценок:
  - После того как пользователь нажал "Открыть в Spotify" — появляется кнопка "Оценить"
  - Оценка по шкале 1-10 или звёздочки (1-5)
  - Опциональный короткий комментарий
  - Статусы: "Слушаю", "Послушал", "Пропустить"
- Сохраняем оценки в Supabase

**Результат фазы:** главный экран с карточкой, можно открыть в Spotify и поставить оценку

---

### Фаза 6 — Социальные фичи
**Цель:** добавлять друзей и видеть их оценки
**Примерное время:** 2 недели

**Что делаем:**
- Система друзей:
  - Поиск пользователей по Spotify username или email
  - Запрос в друзья / принять / отклонить
  - Список друзей
- Лента активности:
  - Видно что оценил каждый друг сегодня / за неделю
  - Их альбом дня (если они захотят делиться публично)
  - Лайки на оценки друзей
- Профиль пользователя:
  - История оценённых альбомов
  - Средняя оценка
  - Жанровые предпочтения (инфографика)

**Результат фазы:** можно добавить друга и видеть что он слушает

---

### Фаза 7 — Полировка и подготовка к релизу
**Цель:** приложение готово к публикации в App Store
**Примерное время:** 2-3 недели

**Что делаем:**
- Push-уведомления: "Твой альбом дня готов!" (каждое утро в удобное время)
- Онбординг для новых пользователей (3-4 экрана объяснения)
- Обработка ошибок: нет интернета, токен Spotify истёк, и тд
- Иконка приложения и сплеш-скрин
- Тестирование на разных iPhone (SE, 14, 15 Pro)
- Сборка через Expo EAS
- Заполнение страницы в App Store (описание, скриншоты, категория)
- Подача на ревью Apple (обычно 1-3 дня)

**Результат фазы:** приложение в App Store

## Как работать с Claude и Claude Code

**Claude Code** (терминал) — для написания кода:
- Открываешь Claude Code в папке проекта
- Описываешь задачу на русском: "сделай экран с карточкой альбома, данные приходят из такой-то структуры"
- Он пишет код, объясняет что сделал
- Ты проверяешь на телефоне через Expo Go

**Claude** (этот чат) — для планирования и вопросов:
- Если что-то непонятно в плане — спрашивай здесь
- Если надо разобраться как что-то работает — спрашивай здесь
- Если надо принять архитектурное решение — обсуждаем здесь

**Важные принципы работы:**
1. Работай фаза за фазой, не прыгай вперёд
2. Каждая фаза заканчивается тем что на телефоне что-то работает — это точка проверки
3. Если что-то сломалось — не паникуй, просто опиши Claude Code что происходит и он починит
4. Коммить код в Git после каждой рабочей фичи (Claude Code умеет это делать)

## Структура базы данных (Supabase)

```
users
├── id
├── spotify_id
├── display_name
├── avatar_url
├── spotify_access_token
└── created_at

user_library (альбомы из Spotify пользователя)
├── id
├── user_id
├── spotify_album_id
├── album_name
├── artist_name
└── synced_at

albums_of_the_day
├── id
├── user_id
├── date
├── spotify_album_id
├── album_name
├── artist_name
├── cover_url
├── genre
├── lastfm_listeners
└── status (pending / listening / rated / skipped)

ratings
├── id
├── user_id
├── album_of_the_day_id
├── score (1-10)
├── comment
└── created_at

friendships
├── id
├── requester_id
├── addressee_id
└── status (pending / accepted)
```

## Следующий шаг прямо сейчас

Начни с Фазы 0 — создай аккаунты:
1. [developer.spotify.com](https://developer.spotify.com) → Dashboard → Create App
2. [supabase.com](https://supabase.com) → New Project
3. [last.fm/api](https://www.last.fm/api) → Get API Key
4. [expo.dev](https://expo.dev) → Sign Up

После этого — установи Node.js с [nodejs.org](https://nodejs.org) (версия LTS) и Expo Go на iPhone из App Store.

Когда всё это готово — открывай Claude Code и говори: _"Создай новый Expo проект для приложения Album of the Day, настрой базовую структуру с навигацией между 4 экранами: Home, Library, Friends, Profile"_
